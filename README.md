# Daily Expense Tracker

## Project Description
The Daily Expense Tracker is a Python-based application that helps users record and manage their daily expenses. It allows users to add, view, and filter expenses based on categories. All expense records are stored permanently in a CSV file using Python's built-in CSV module.

## Features
- Add daily expenses with date, category, description, and amount.
- View all recorded expenses.
- Filter expenses by category.
- Calculate total expenses.
- Display category-wise expense summaries.
- Store expense records permanently in a CSV file.
- Read and write CSV files using Python's CSV module.

## Technologies Used
- Python
- CSV Module
- File Handling

## How to Run
1. Install Python on your system.
2. Download or clone the project.
3. Open the project folder in VS Code.
4. Run the Python script.
5. Select the required option from the menu.
6. Add, view, or filter your expenses.

## Storage
All expense records are saved in a CSV file named `expenses.csv`. The stored data remains available even after closing the application.

## Learning Outcomes
- Understanding Python file handling.
- Working with CSV read and write operations.
- Managing structured data.
- Using lists, dictionaries, loops, and conditional statements.
- Calculating category-wise statistics.

## Conclusion
This project provides a simple way to track daily expenses and understand spending habits while improving practical Python programming and file-handling skills.
